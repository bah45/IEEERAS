# IEEE RAS — Robotics & Automation Society Website

A modern, responsive and professional website concept for the **IEEE Robotics and Automation Society (IEEE RAS)**, designed to showcase robotics research, automation, events, chapters, publications, resources and community activities.

The project focuses on combining **IEEE's professional identity with a modern robotics-focused digital experience**.

---

## 🚀 Overview

The IEEE RAS website is designed as a centralized platform for:

* 🤖 Robotics & automation research
* 🧠 Artificial intelligence and autonomous systems
* 🌐 IEEE RAS chapters and communities
* 📅 Conferences, workshops and events
* 📚 Publications and technical resources
* 📰 Latest IEEE RAS news
* 👥 Membership and community engagement
* 🎓 Student and educational opportunities

The design emphasizes **clarity, accessibility, responsiveness and strong visual storytelling**.

## 🎨 Design System

The interface follows a clean and futuristic engineering aesthetic.

### Color Palette

| Role       | Direction            |
| ---------- | -------------------- |
| Primary    | IEEE-inspired Red    |
| Background | White / Light Gray   |
| Text       | Deep Navy / Charcoal |
| Secondary  | Medium Gray          |
| Accent     | Soft Red             |

Red is primarily used for **CTAs, active states, links and important highlights**.

### Typography

Recommended fonts:

* **Inter**
* **IBM Plex Sans**
* **Space Grotesk**

The typography system uses large bold headings, readable body text and compact technical labels.

## 📱 Responsive Design

The website is designed for multiple screen sizes.

| Device  |  Frame |
| ------- | -----: |
| Desktop | 1440px |
| Tablet  |  768px |
| Mobile  |  390px |

The layout adapts using responsive grids, Auto Layout and component variants.

### Desktop

* Full navigation
* Multi-column layouts
* Large hero sections
* Expanded content grids

### Tablet

* Reduced columns
* Condensed navigation
* Two-column layouts

### Mobile

* Hamburger navigation
* Single-column layouts
* Stacked cards
* Full-width CTAs
* Optimized typography and spacing
